Contexto del Sistema
Propósito:
 El Sistema de Gestión de Solicitudes permite registrar, revisar y resolver solicitudes internas de una organización, manteniendo trazabilidad, auditoría e historial de cambios.

Actores
Empleado
Utiliza el sistema para:
+ Crear solicitudes.
+ Consultar estado de solicitudes.
+ Revisar historial de sus solicitudes.

Supervisor
Utiliza el sistema para:
+ Revisar solicitudes.
+ Aprobar solicitudes.
+ Rechazar solicitudes.

Administrador
Utiliza el sistema para:
+ Gestionar usuarios.
+ Consultar auditoría.
+ Consultar información global del sistema.

Sistemas Externos
Versión 1
 - No existen integraciones externas.

Posibles integraciones futuras
 + Servicio de correo electrónico para notificaciones.
 + Sistema corporativo de usuarios.
 + Sistema ERP. 

Límites del sistema
El sistema es responsable de:
+ Gestionar solicitudes.
+ Gestionar estados.
+ Registrar auditoría.
+ Registrar comentarios.

El sistema no es responsable de:
* Firma electrónica.
* Gestión documental.
* Integración con sistemas financieros.
* Aplicaciones móviles.
